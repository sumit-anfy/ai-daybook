# This knowledge base — OKF setup

One corpus for every part of life, so a bakery decision and a garden lesson can
link to each other.

## Ground rules

- Notes are written through the Librarian (`create_node`, `update_node`). It
  assigns ids, files notes, and refuses invalid ones.
- Live data stays in its own app; the corpus points at it (see the decision on
  tasks).
- Every session ends with the close-out playbook.
